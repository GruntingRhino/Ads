# LiveImproved Ad System

Creative direction:
- masculine, assertive, high-performance voice
- dark, cinematic, data-driven visuals
- outcome-first positioning
- pain -> visibility -> coaching -> transformation
- hooks first, proof second, CTA last

Ad construction principles:
- Open with a specific pain or identity hook in the first 1–2 seconds
- Keep voiceover lines short, punchy, and direct
- Show the product doing the work instead of describing it
- Use transitions, motion, and visual rhythm so the frame never feels static
- Finish with one clear command CTA

Each ad lives in its own folder and is rendered as its own vertical video.
